# Contributing to quantara-toolkit

This repo is a placeholder for future Quantara developer tooling (CLI, runtime,
examples) — see [README.md](README.md) for why it's currently empty of code.

## What's useful to contribute right now

- **Design discussion**: open an issue proposing CLI commands, flags, or config
  shape (`cli/`), or runtime architecture (`runtime/`).
- **Documentation**: if you spot something unclear in the roadmap, a docs PR is
  welcome.

## What's not ready yet

Implementation PRs for the CLI or runtime are premature until the MVP
(`quantara-core` + `quantara-web`) has stabilized and there's a concrete design to
build against. If you want to write code today, those two repos are the ones with
open `good-first-issue`s.

## Code of Conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). Be kind.
