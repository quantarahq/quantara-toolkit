# Examples (planned)

Example projects showing how to use the future Quantara CLI (`cli/`) end to end.

## Status

Not started — there's nothing to write examples for yet, since `cli/` hasn't been
built. Once it has, this directory will hold small, runnable projects (e.g. "scaffold
a project with `quantara init`, deploy it, inspect it in the dashboard") that double
as onboarding material and manual regression checks.

## In the meantime

For a working example of the full Quantara flow today, see the API walkthrough in
[quantara-core's architecture doc](https://github.com/quantarahq/quantara-core/blob/main/docs/architecture.md)
or just use the dashboard at `quantara-web`'s `/dashboard` route.
